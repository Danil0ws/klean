# klean

Безопасный и эффективный CLI для очистки среды разработки.

## Установка

**Homebrew (macOS/Linux)**
```sh
brew tap klean-cli/klean
brew install klean
```

**Cargo**
```sh
cargo install klean
```

**Scoop (Windows)**
```sh
scoop bucket add klean https://github.com/klean-cli/scoop-bucket
scoop install klean
```

**Прямая загрузка** — скачайте последний бинарный файл со страницы [Releases](https://github.com/danil0ws/klean/releases).

## Использование

```
klean                   # интерактивное меню (TUI)
klean .                 # сканировать текущий каталог
klean ~/projects        # сканировать указанный путь
klean globals           # управление глобально установленными пакетами
klean update            # обновить до последней версии
klean undo              # восстановить последнюю удалённую сессию из корзины
klean trash             # список сессий в корзине
klean trash --empty     # очистить корзину
klean stats             # показать историю очистки
```

### Интерактивное меню

Запуск `klean` без аргументов открывает меню TUI:

| # | Действие |
|---|----------|
| 1 | Очистить артефакты — удалить кэши сборки, node_modules, dist, … |
| 2 | Глобальные пакеты — управление npm/cargo/pip/brew/бинарными файлами |
| 3 | Статистика — история очистки |
| 4 | Обновить *(отображается только при наличии новой версии)* |
| 4/5 | Выход |

Навигация: `↑↓` или `jk`, подтверждение: `Enter` или цифровая клавиша.

### Глобальные пакеты

`u` — проверить устаревшие пакеты (метки появятся в колонке «Версия»).  
`Пробел` — выбрать, `a` — выбрать всё, `Enter` — удалить выбранное.  
`s` — переключить сортировку между менеджером и размером.

## Что очищается

klean удаляет: `node_modules`, `target`, `.cache`, `dist`, `build`, `.next`,
`.nuxt`, `__pycache__`, `.venv`, `vendor` и многое другое — для 20+ языков
и фреймворков. Конфигурация per-project через `klean.toml`.

## Конфигурация (`klean.toml`)

Разместите `klean.toml` в корне проекта для настройки поведения:

```toml
[project]
backup = true          # перемещать в корзину вместо удаления
backup_dir = ".trash"  # пользовательское расположение корзины

[[ignore]]
path = "dist"          # не трогать этот каталог
```

## Самообновление

```sh
klean update           # обновить до последней версии
klean update --dry-run # только предварительный просмотр
```

klean проверяет последнюю версию на crates.io и устанавливает через
`cargo install` (если доступен), или загружает готовый бинарный файл
с GitHub Releases.
